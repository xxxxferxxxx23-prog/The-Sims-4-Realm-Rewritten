# Sims 4 Realm of Magic Overhaul

## Features
- Enhanced skill trees for magic schools
- Magical romance systems
- Dynamic quests
- Lore-driven events

## Installation
1. Download the mod files.
2. Place in Documents/Electronic Arts/The Sims 4/Mods/
3. Ensure Sims4CommunityLib is installed if used.
4. Enable script mods in game options.

## Compatibility
- Requires The Sims 4: Realm of Magic (EP08)
- Not compatible with mods altering same tuning IDs

## Usage
Once installed, new options appear in spellbook, social interactions, etc.
